# Transcriber

Плагин для Exteragram, который заменяет стандартную платную расшифровку Telegram на бесплатные современные альтернативы без необходимости подписки Telegram Premium.

## Описание
Служит для бесплатного и неограниченного перевода голосовых сообщений и «кружков» (видеосообщений) в текстовый формат.

## Функционал
* **Выбор AI-моделей**: Поддержка нескольких современных провайдеров распознавания речи:
  * Universal-2 (AssemblyAI)
  * Nova-3 (Deepgram)
  * Voxtral (Mistral)
  * Gemini Flash Latest (Google)
* **Разделение спикеров**: Автоматическая диаризация диалогов (маркировка спикеров A, B, C и т.д.).
* **Экономия трафика**: Конвертация видеосообщений в аудио перед отправкой на сервера распознавания (ускоряет работу на медленном соединении).
* **Поддержка прокси**: Возможность работы через SOCKS5, включая автоматическое подтягивание настроек из плагина **GreenPass**.

## Установка и использование
1. Установите и активируйте плагин в Exteragram.
2. В настройках плагина выберите желаемую модель и укажите её API-токен.
3. Нажмите на иконку расшифровки рядом с любым аудио- или видеосообщением в чате.

## Настройки
* **Режим подключения**: Единый селектор для настройки сети:
  * *Отключено* — прямое соединение.
  * *Прокси GreenPass* — автоматическое использование прокси-канала из соседнего плагина GreenPass.
  * *Вручную SOCKS5* — раскрывает поля для ручного ввода хоста, порта и данных авторизации SOCKS5-прокси.
  * *Кастомный DNS* — раскрывает поле DNS-сервера; по умолчанию используется `dns.dns-ai.ru` через DNS-over-TLS.
* **Отправлять только аудио**: Снижает объем загружаемого трафика для видеосообщений.
* **Разделять говорящих**: Включает разметку собеседников.

## История изменений (Changelog)
* **Версия 2.4.7**:
  * Исправлен DNS-over-TLS: добавлен импорт `ssl`, проверка сертификата и bootstrap по опубликованным IPv4-адресам DNS-AI.
  * Убран заведомо неработающий UDP/53 fallback для DNS-AI.
* **Версия 2.4.0f**:
  * Добавлен единый селектор выбора режима подключения (Connection Mode) с динамически раскрывающимися полями ввода.
  * Полностью удален раздел настроек «Другое» и кнопка перехода в канал.
* **Версия 2.3.2f**:
  * Добавлена функция **Кастомного DNS** для обхода блокировок API Gemini / Deepgram на уровне доменного разрешения (UDP-запросы к обходным DNS).
  * Класс плагина переименован с `TestPlugin` на `TranscribePlugin` для устранения коллизий с другими плагинами в Exteragram (плагин теперь корректно отображается в списке плагинов).
  * Изменен автор плагина на `@monekgen`.
  * Установлена новая иконка плагина через стикерпак `monek_icons/1`.
* **Версия 2.3.1f**:
  * Интегрировано автоматическое использование прокси-соединения из плагина **GreenPass** при помощи API `greenpass_proxy_api`.
  * Версия по умолчанию переключена на автоматический импорт настроек прокси.
* **Версии < 2.3.1f**:
  * Исходная реализация расшифровки (AssemblyAI, Deepgram, Mistral, Gemini).
  * Ручные настройки прокси SOCKS5.
